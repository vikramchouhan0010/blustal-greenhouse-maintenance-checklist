# Greenhouse and polyhouse maintenance checklist

Seasonal checks that extend structure life: inspect film fixings and clips for wear, check profile and spring tension, clear gutters and drains, look for rust at joints and base plates, clean and test fogging and drip lines, and replace damaged net or film before the monsoon.
